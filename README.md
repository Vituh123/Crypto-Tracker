# 🚀 Crypto Tracker Pro

Um dashboard moderno e interativo de monitoramento de criptomoedas em tempo real, desenvolvido com **JavaScript puro (Vanilla JS)** e consumindo dados públicos da **CoinGecko API**.

## 🛠️ Funcionalidades

- **Consumo de API REST:** Requisições assíncronas (`fetch` com `async/await`) para buscar os dados das principais criptomoedas do mercado.
- **Busca Dinâmica em Tempo Real:** Filtro instantáneo de ativos por nome ou símbolo (ex: Bitcoin, BTC).
- **Conversor de Moedas:** Alternância em tempo real entre Dólar (USD), Real (BRL) e Euro (EUR), com atualização automática de símbolos e valores.
- **Auto-Refresh Inteligente:** Atualização automática dos dados a cada 30 segundos em segundo plano, com indicador visual de status (*"Em direto"* / *"Atualizado agora"*).
- **Design Responsivo & Dark Mode:** Interface elegante com foco em experiência de usuário (UX) utilizando CSS moderno e Flexbox.

## 💻 Tecnologias Utilizadas

- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização avançada e Dark Theme)
- **JavaScript Moderno (ES6+)** (Manipulação do DOM, eventos, temporizadores e requisições HTTP)
- **CoinGecko API** (Fonte de dados de mercado)
